## 1. 背景

AR021→AR042 累积了 12 个可组合开关。用户要求：**聚合不等于最优**，需要判定哪些 AR 组合后真正提升综合性能，
无法提升的**回退**到上一步最优组合。

## 2. 需求

- F1 建立**真实**兼容性矩阵（以代码校验为准，不凭记忆）；
- F2 用同一基准实测候选组合（baseline / kv-only / spec / quality / latency）；
- F3 **回退规则**：若某机制不改善最佳组合（更慢或质量相同但更慢），将其从最佳组合中剔除并记录依据；
- F4 把最佳组合固化为**一等公民预设**（`fastdllm_preset`），未知预设与非法覆盖 fail-fast；
- F5 文档给出决策表、被剔除开关清单与复现命令。

## 3. 验收标准

- Given 任一预设，Then 可构造并可直接用于 `FastDLLMSampler`；
- Given 被剔除的开关，Then 在所有预设中均为关，且 `PRESET_REJECTED_KNOBS` 有实测原因；
- Given 基准运行，Then 产出最佳质量臂/最佳延迟臂/叠加增益/复现四项判定；
- Given 宿主争用导致计时离群，Then 如实标注并以干净运行为决策依据（不得用噪声下结论）。

## 4. 约束

真实 checkpoint、无 mock；质量代理为同模型 mean log p（AR037 口径）；`stop_token_id=-1`。
