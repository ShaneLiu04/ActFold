## 0. T001 测量结论（已执行，作为本 AR 的事实基础）

真实 checkpoint、192 token 长几何（`stop_token_id=-1`）、同一 prompt：

| 指标 | A 非缓存基线 | D 缓存×投机 |
|---|---|---|
| mean log p（质量代理，越大越好） | -2.1162 | **-2.0870** |
| 低置信度已提交位 (<0.5) | 48/223 | 43/223 |
| 墙钟 | 172.4 s | **18.3 s（9.4×）** |
| token 逐位一致率 | — | 0.4260 |

**结论 1（负面结论修正）**：README 限制项 14「多块长生成质量塌缩」**不成立**。逐位一致率低是
「整块贪心提交 vs 阈值重掩码迭代」的合法轨迹分歧，不是质量退化——同模型似然 D 略优于 A。

**结论 2（规模修正）**：长几何的真实加速是 **~9.4–10×**（192/320 token 实测 9.4×/10.0×），
短几何（34/66 token）的 8.73× **低估**了框架优势。

**结论 3（新机会）**：`sb=block=32` 下贪心行几乎总是胜出（AR034 T007：100%），所以 `[N=4,B]` 验证
多数时候只是在「确认贪心行」。若能用**草稿自身置信度**判定「该块无需验证」，即可再省一次前向；
与 AR036 CDF 组合时该块只需 **1 次前向**（融合前向同时提交并给出下一块草稿）。

## 1. 目标

`FastDLLMSamplerConfig.adaptive_candidate_budget`（默认关）：草稿阶段计算**仍掩码位上的贪心 token 概率**，
若其最小值 ≥ `candidate_budget_threshold`，则**跳过 `[N,B]` 验证**、直接整块提交贪心行；
否则走原 AR034/AR036 路径。账本 `spec_budget_skips`。目标：在质量不退化（似然不降）前提下进一步降低前向数。

## 2. 需求范围

**In Scope**：ACB 开关与跳过逻辑、账本、UT、长几何基准（A/D/S 三臂）、文档与限制项修正。
**Out of Scope**：改 `threshold` 重掩码语义；batch>1；LLaDA/Dream；折叠路径；SCR（本轮不做，见 §6）。

## 3. 功能需求

### F1 跳过判定

**描述**：在草稿决策行上取仍掩码位置的贪心 token 概率 `p_g`，`min(p_g) >= candidate_budget_threshold` 即跳过验证。

**触发条件**：`adaptive_candidate_budget=True`、组合臂生效、`num_masked > 0`。

**验收标准**：
- Given 置信达标，When 该块处理，Then **不发生** `[N,B]` 验证前向，`spec_budget_skips += 1`，提交内容 == 贪心草稿行；
- Given 置信未达标，Then 走原验证路径，`spec_budget_skips` 不变，输出与 ACB 关闭态**逐字节一致**。

### F2 与 CDF 组合

**描述**：跳过验证时，若草稿来自 CDF stash，则该块 **0 次额外前向**；否则 1 次（草稿）。

**验收标准**：Given ACB+CDF 同时开启且置信达标，When 该块跳过，Then 该块前向数 = 0（账本可核）。

### F3 账本

**描述**：`history_cache_stats` 新增 `spec_budget_skips`；默认关为 0。

### F4 质量门

**描述**：ACB 不得显著降低似然。

**验收标准**：Given 长几何，When 对比 A/D/S 的 mean log p，Then S ≥ D − 0.05（预注册容差；不达标即如实 refuted）。

## 4. 非功能需求

| 类型 | 指标 | 要求 |
|------|------|------|
| 性能 | 跳过率 | 记录实测 `spec_budget_skips / spec_verify_forwards`（诚实验证收益上界） |
| 性能 | p50 | S vs D 记录（不设强制阈值，因 launch 省 1/2 时收益取决于跳过率） |
| 质量 | 似然 | S ≥ D − 0.05 |
| 兼容 | 默认关 | 与 AR036 末态逐字节一致 |

## 5. 约束与假设

- 真实 checkpoint、无 mock；冻结判定；单次运行；
- 长几何必须 `--no-eos`（否则 34 token 早停，一切多块结论无效）；
- 假设：草稿置信度与「贪心行是否会被验证选中」高度相关（AR034 T007 100% 胜率为其经验依据）。

## 6. 已知风险（诚实声明）

若实测跳过率很低（例如 <20%），则 ACB 的收益有限——按 AR035 先例**如实交付为「计算面安全旋钮」**，
不包装成加速档。自校正重掩码（SCR）在 T001 结论不成立后**不再需要**，从范围中移除。
