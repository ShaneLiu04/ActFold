# Pinned constraints for the benchmark backends.
#
# `evalplus` depends on `google-generativeai`, whose gRPC/protobuf transitive
# graph makes pip backtrack across hundreds of `grpcio-status`,
# `googleapis-common-protos` and `proto-plus` releases (observed >10 minute
# stalls and CI job cancellation). These constraints pin the stack that the
# resolver itself converges to, keeping installation deterministic and fast.
#
# Install with:
#     pip install -r requirements-bench.txt -c constraints-bench.txt
# `requirements-bench.txt` already includes this file via `-c`.
