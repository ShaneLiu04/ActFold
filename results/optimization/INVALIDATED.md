`opt4/` 下所有 JSON 与 `figures/`）。

## 失效原因

1. **跨版本对比不受控（M-5）**：`baseline/` 与 `opt*/` 产物产生于不同时间的
   两次运行，GPU 时钟/热状态未受控，"优化前 vs 优化后"的对比不满足方法学
   要求（应在同日同机交错重跑）。
2. **单次测量无方差（T020）**：所有时延数字为单次测量，无 std、无种子；
   新方法学要求 repeats≥3、种子受控、报告 mean±std。
3. **被测实现已再次变更（M2/M3）**：opt1 缓存基准测量于旧的逐 token 掩码
   读取路径；fetch/get_all 与连续缓冲重写后数值失真。opt4 融合基准的实现
   亦经 Triton kernel 修复（单边读/stride/tail-mask）。
4. **成本/FLOPs 口径变更（T021/T022）**：涉及 FLOPs 换算的数字需按新计数器
   口径重算。

## 处置

- 本目录产物**不得引用**；重跑需在同日同机、锁定 GPU 时钟、repeats≥3 且
  种子记录的条件下进行，`baseline` 与优化版本交错运行。
- 重跑命令与环境要求见 `docs/RERUN_CHECKLIST.md`。
